# Installer Build Guide

# SI5351 Multi-Radio VFO Control Platform

This document describes how to build the Windows installer package for the SI5351 Multi-Radio VFO Control Platform.

---

# PURPOSE

The installer allows non-programmer ham radio operators to install the software like a normal Windows application.

Goals:

- Simple installation
- No Python installation required
- Start Menu shortcuts
- Optional desktop shortcut
- Clean uninstall support
- Professional distribution package

---

# INSTALLER ARCHITECTURE

Current packaging flow:

```text
Python Source
    ↓
PyInstaller EXE Build
    ↓
Standalone Package Folder
    ↓
Inno Setup Installer
    ↓
SI5351_Multi_Radio_VFO_Setup.exe
```

# REQUIRED INPUT PACKAGE

The installer requires the EXE package folder generated by:

```text
installer/build_exe.ps1
```

Expected package folder:

```text
pc_software/dist/SI5351_Multi_Radio_VFO/
```

Expected contents:

```text
SI5351_Multi_Radio_VFO.exe
radio_profiles.json
app_settings.json
```

---

# INSTALLER SCRIPT

Installer configuration script:

```text
installer/SI5351_Multi_Radio_VFO.iss
```

The `.iss` file controls:

- installation directory
- files copied
- shortcuts
- installer graphics
- uninstall behavior
- version information

---

# IMPORTANT GITHUB RULE

Do NOT commit generated installer EXE files into normal repository source tree.

Use:

```text
GitHub Releases
```

for publishing installer binaries.

Repository should primarily contain:

- source code
- scripts
- documentation
- installer definitions
